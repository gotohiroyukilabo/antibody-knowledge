# Day 048：競合関係で抗体を分類する

## 今日の問い

二つの抗体が同じ抗原へ同時に結合できるかを測ると、抗体群をどう分類でき、そこからエピトープについてどこまで言えるのだろうか。

## 本文

### 1. エピトープビニングは「住所の特定」ではなく「競合関係の分類」である

**エピトープビニング（epitope binning）**は、同じ抗原を認識する抗体を二つずつ組み合わせ、一方が結合した後に他方も結合できるかを調べる競合assayである。互いの結合を妨げる抗体は似た競合profileをもつ**bin**へ、同時結合できる抗体は異なるbinへ整理する[1,2]。抗体が`n`本なら向きを区別した全組合せは最大`n × n`で、100本では10,000測定になるため、高スループットSPR imagingやBLIが利用される[3]。

重要なのは、binが残基レベルのepitopeと同義ではないことである。二抗体の接触残基が一部または全部重なれば競合するが、隣接した別部位でもIgGやFabの大きさによる**steric hindrance（立体障害）**で同時結合できないことがある。逆に、部分的に近い部位でも結合角度が異なればsandwichを作れる。さらに第一抗体が抗原の構造を変え、第二抗体の部位を閉じるallostericな競合もあり得る。したがって「同じbin」は「同じ、または近接・連動する抗原面を使う」という作業仮説であり、「同じ残基へ結合する」という確定ではない[2,3]。

### 2. 基本は第一抗体で占有し、第二抗体の追加結合を測る

典型的な**classical sandwich**では、固定化した抗体Aで抗原を捕捉し、抗体Bを流す。Bの追加signalがあればAとBは同時結合可能、signalがなければ競合候補である。**in tandem**ではセンサー上の抗原へA、次いでBを順に結合させる。**premix**では抗原と過剰量のBを溶液中で先に混ぜ、その複合体が固定化Aへ結合できるかを見る。Abdicheらはこれら三形式を複数のSPR/BLI装置で比較し、明瞭な系では整合するbinを得られることを示した[1]。

測定値は多くの場合、第二抗体の結合responseを「抗原のみ」などのcontrolに対して正規化し、block、non-block、ambiguousへ閾値分類する。閾値の近くを機械的に二値化せず、生sensorgram、replicate、濃度依存性を見る。第一抗体が抗原を十分飽和していなければ、本来競合するBが空いた部位へ結合して偽のnon-blockになる。反対に、過度な固定化、抗原凝集、非特異的結合は偽のblockを生み得る。

対角線の**self-block**は重要な陽性対照である。同じ抗体をAとBに使えば通常は第二結合が抑えられる。self-blockしない抗体は、第一抗体の飽和不足、抗原の多量体化・不均一性、固定化失活などを疑う。無関係IgG、抗原なし、既知の競合／非競合抗体も含め、signalの意味を固定してから全matrixを読む[4]。

### 3. 競合matrixは両方向とnetworkで読む

行を第一抗体、列を第二抗体としたheatmapでは、赤をblock、緑をsandwich、黄をambiguousなどとして全ペアを並べる。A→BとB→Aの両方向が一致すれば解釈しやすい。各抗体をnode、競合関係をedgeとするnetworkに変換すると、似たprofileのcluster、複数binをつなぐ抗体、孤立した抗体を把握できる[3]。

ただし競合関係は必ずしも単純な同値関係ではない。AがBと競合し、BがCと競合しても、AとCが同時結合できることがある。大きな抗体footprintが隣接する二領域へまたがる場合などで、これは矛盾ではなく「重なり合う抗原面」の情報である。またA→Bだけblockする**asymmetric blocking**は、固定化方向、affinityや`koff`の差、標識、立体配置、抗体による置換の影響を示す可能性がある。高親和性抗体が先行抗体を置換して見かけの非対称性を作る例も報告されており、片方向を平均して消すのではなく、抗体の向きを反転し濃度を振って再測定する[5]。

### 4. 抗原の状態がbinを変える

精製抗原が単量体か多量体か、nativeな糖鎖と立体構造を保つかは結果を左右する。凝集体では異なる抗原分子へAとBが同時結合し、同じepitopeでもsandwichに見える。固定化で一部の構造が壊れれば、特定抗体だけが結合不能になる。抗原sampleに異なるconformerや切断体が混ざると、相反する競合patternが生じ得る。実際、抗原の内在的またはassay誘導性の不均一性が誤ったbin解釈を招くことが示され、溶液抗原を使う形式とnative抗原での直交確認が推奨されている[6]。

膜タンパク質では可溶性domainと細胞表面full-lengthでaccessibilityが違う。目的が細胞上の作用機序なら、精製抗原のSPR/BLIだけで終えず、flow cytometryによる競合、ligand遮断、細胞signalなどへ戻す。binningは抗原表面の相対的な地図であり、試料・抗体format・assay条件を変えても不変とは限らない。

### 5. 候補選択ではbinと機能を重ねる

抗体探索では、最高affinityのcloneだけを残すと同じ機能epitopeへ候補が偏ることがある。まず異なるbinから代表抗体を残し、各binにneutralization、受容体遮断、agonismなどの機能dataを重ねれば、epitope diversityを維持したまま候補を絞れる。大規模な比較では、panelに含む抗体の多様性が増えるほど微妙な競合差を識別しやすく、binと機能の関連も示されている[3]。

非競合の二抗体はsandwich assayのcapture/detection pairや、多点認識による抗体cocktailの候補になる。ただし「異なるbin」だけで相乗効果やescape耐性は保証されない。SARS-CoV-2研究では、非重複epitopeを同時に狙うcocktailがescapeを抑えた例があるが、これは構造、変異scan、neutralization、escape selectionを組み合わせた結論である[7,8]。binningは候補pairを絞る入口であり、作用機序を確定する終点ではない。

### 6. 論文では「測定事実」と「構造的解釈」を分ける

測定事実は「この濃度・順序・抗原状態で第二抗体のsignalが低下した」である。そこから「競合する」、さらに「epitopeが重なる」と解釈が進むたびに仮定が増える。論文を読むときは、全pairを両方向で測ったか、self-blockと既知controlが成立したか、ambiguousをどう扱ったか、代表抗体だけでなく全matrixを示したかを確認する。

残基レベルの主張には、Day 47で学んだalanine scan、HDX-MS、X線結晶構造、cryo-EMなどが必要である。binningとmappingを組み合わせれば、「抗体群の関係」と「実際の接触面」を別々の証拠から統合できる。良い結論は、競合matrix、物理的epitope、細胞機能の三層が整合している。

## 図または比較表

```text
抗体Aを先に結合
       │
       ├─ 抗体Bの追加signalあり → sandwich可能 → 異なるbin候補
       │
       └─ 追加signalなし／低下   → block          → 同じ・近接bin候補
                                            │
                         向き反転・濃度・controlで再確認
                                            │
                         mappingと機能assayで作用機序を検証
```

| 観察 | まず考える解釈 | 代替説明・次の確認 |
|---|---|---|
| A→B、B→Aともblock | epitopeが重なる／近接する | 立体障害・allosteryをmappingで区別 |
| 両方向ともsandwich | 同時結合可能な異なる領域 | 多量体抗原への別分子結合を確認 |
| 一方向だけblock | 非対称な配置・kinetics | 向き反転、濃度系列、sensorgram確認 |
| self-blockしない | assayが成立していない可能性 | 飽和、抗原均一性、固定化活性を確認 |
| 部分的なresponse | partial／ambiguous | replicateと閾値感度、抗体純度を確認 |

## 論文を読むためのポイント

1. **assay形式と向き**：classical sandwich、in tandem、premixのどれか。行と列は何を表すか。
2. **抗原の状態**：単量体、凝集体、可溶性domain、細胞表面full-lengthのどれか。
3. **成立確認**：self-block、無関係IgG、抗原なし、既知の競合／非競合controlがあるか。
4. **判定法**：responseの正規化、block閾値、ambiguousの扱い、replicateが明記されているか。
5. **両方向性**：A→BとB→Aを測り、非対称性を欠測やnoiseと区別したか。
6. **結論の解像度**：競合binだけから同一接触残基を断定せず、mappingと機能で検証したか。

“Antibodies were assigned to the same epitope bin” は、「このpanelと条件で似た競合profileだった」という意味であり、「原子レベルで同一のepitopeだった」と読み替えない。

## 抗体×AIとの接続

競合matrixは、抗体をnode、block／sandwichをedgeとするgraph dataとして扱える。clusteringやcommunity detectionで代表cloneを選び、配列・構造・affinity・機能を重ねれば、同じclonotypeに偏らない候補選択やcocktail提案を支援できる。ただし二値化前の連続response、両方向、濃度、replicate、抗原lot、assay形式を保持することが重要である。

教師labelとして使う場合、「同じbin＝同じ残基epitope」「sandwich＝遠い構造部位」と置くとlabel noiseが入る。未測定pairをnon-blockにせずunknownとし、asymmetricやambiguousを独立状態として残す。分割はランダムな抗体pair単位ではなく、抗体clonotypeと抗原をまたぐgroup単位にしなければ、同じ抗体や近縁配列がtrainとtestへ漏れる。AIの役割は未測定pairや代表抗体を優先順位づけすることであり、最終的なedgeは実験で確定する。

## 重要用語（8語）

- **epitope binning**：抗体間の競合profileに基づいて抗体群を分類する方法。
- **bin**：似た競合関係を示す抗体の群。残基レベルepitopeそのものではない。
- **classical sandwich**：固定化抗体で抗原を捕捉し、第二抗体の追加結合を測る形式。
- **in tandem**：センサー上の抗原へ二抗体を順番に結合させる形式。
- **premix**：抗原と競合抗体を溶液で先に混ぜ、固定化抗体への結合を測る形式。
- **self-block**：同じ抗体を両役割に使い、第二結合が抑えられることを確認する対照。
- **asymmetric blocking**：抗体を加える順序または固定化方向で競合判定が変わる現象。
- **steric hindrance**：分子の大きさや配置により、別分子の接近・結合が妨げられること。

## 理解確認問題2問と各問題の簡潔な模範回答

### 問1

抗体AとBが両方向で競合した。両者は抗原上のまったく同じ残基へ結合すると結論してよいか。

**模範回答：** 結論できない。接触残基の重複に加え、隣接部位での立体障害やallosteryでも競合するため、残基レベルの主張には変異解析や複合体構造などが必要である。

### 問2

Aを先にするとBをblockするが、Bを先にするとAは結合できた。この結果をどう扱うべきか。

**模範回答：** 平均して一方へ決めず、asymmetric blockingとして残す。固定化方向、飽和度、affinity・`koff`、抗体置換を疑い、向き反転と濃度系列を含む再測定で確認する。
