# Day 057：無細胞ディスプレイと巨大ライブラリ

## 今日の問い

細胞を使わずに、どうすれば10^12〜10^14規模の候補から抗原結合分子を選び、その結合性を正しい遺伝子配列へ対応づけられるのか。

## 本文

### 1. displayの核心は「表現型を遺伝子型へつなぐ」こと

抗体libraryからbinderを選ぶには、抗原へ結合したタンパク質という**表現型**と、それをコードする核酸という**遺伝子型**を物理的に結ぶ必要がある。phageやyeast displayでは細胞へのDNA導入がlibrary規模を制限する。**ribosome display**と**mRNA display**は転写・翻訳を試験管内で行い、形質転換を省くため、一般に10^12〜10^14程度の候補を扱える[1–5]。

ただし理論多様性と、実際に選択へ参加する**effective library size**は異なる。DNA合成、翻訳、folding、連結、回収のたびに分子が失われる。10か所の完全ランダム化は20^10、約10^13通りだが、入力分子数や連結効率が不足すれば網羅できない[5]。

この違いは論文の数字を読むときに重要である。「10^14 diversity」と書かれていても、それが設計上の組合せ数、合成DNA分子数、連結済み分子数のどれかで意味が変わる。各配列を平均1回見るだけでも希少cloneを取り逃しやすく、通常はlibrary sizeを上回る分子を投入してcoverageを確保する。

### 2. ribosome displayは三者複合体を一時的な選択粒子にする

ribosome displayでは停止コドンを除いたmRNAを無細胞翻訳する。終結できないため、新生抗体断片はpeptidyl-tRNAを介してribosomeに、ribosomeはmRNAに結合したままになる。C末端spacerは抗体をribosome tunnelの外へ出し、foldingを助ける。この三者複合体を固定化抗原で選び、残ったmRNAを回収・逆転写・PCRして次roundへ進む[1–3]。

1994年には10^12種のpeptide library、1997年にはscFvの5 cyclesで10^8倍濃縮が報告された[1,2]。抗原濃度を下げる、可溶性抗原との競合で解離の速いcloneを落とす、PCRで変異を加える操作を反復できる。off-rate選択とDNA shufflingでscFvを進化させた例もある[6]。一方、三者複合体は非共有結合なので、低温や高Mg^2+などribosomeを保つ条件が必要であり、強い洗浄や変性条件には制約がある。

この方法では、選択のたびに生きた細胞へ戻す必要がない。したがって同じ配列集合を増幅して変異を足し、次roundで別の選択圧へすぐ移せる。ただしPCRの自然な誤りも変異となるため、意図した親和性成熟と増幅由来の変化を区別するにはroundごとの配列追跡が必要である。

### 3. mRNA displayはpuromycinで共有結合を作る

mRNA displayではmRNAの3′側へ**puromycin**を連結する。puromycinはaminoacyl-tRNAを模倣し、新生polypeptideのC末端へ共有結合する。「タンパク質–puromycin–mRNA」融合体を作り、通常は逆転写後に抗原選択する。RobertsとSzostakが1997年にこの原理を示した[4]。

共有結合なので選択中にribosomeを保つ必要がなく、温度、塩、洗浄条件の自由度が高い。scFvを4 rounds選択し、`koff`を一桁以上遅く、`KD`を約30倍改善した例がある[7]。約10^12分子のscFv libraryをmicrofluidic chipで選んだ報告もある[8]。

puromycin fusion形成は100%ではなく、連結効率はeffective libraryを縮める。RNAの安定性やRT・PCR効率もbias源になる。scFvは扱いやすいが、Fabでは重鎖・軽鎖と両遺伝子のペアを保つ追加設計が必要である。emulsion PCRでH鎖・L鎖遺伝子を対応づけた実証は、この難しさを示す[9]。

共有結合の利点は「必ず高親和性が得られる」という意味ではない。高温、塩、競合物質などを使えるのは、その条件に耐えて結合する分子へ目的関数を変えられるという意味である。逆に、翻訳後のfolding環境が最終的な哺乳類発現と異なれば、有望なIgG配列を早期に失う可能性もある。

### 4. 巨大libraryでも、選択は直接のaffinity測定ではない

選択後に増えた配列は、「抗原に捕捉され、洗浄を生き残り、核酸として回収・増幅された」配列である。濃縮度は`KD`だけでなく、翻訳量、folding、`kon`、`koff`、固相化抗原、非特異結合、PCR効率を混ぜる。negative selectionがなければ、ビーズやtagへのbinderも増え得る。

各roundのinput量、抗原濃度、洗浄時間、competitor、回収率、PCR cyclesを記録し、no-antigen beadsや無関係抗原を対照に置く。最終候補はfusionから切り離し、可溶性scFv、Fab、IgGとして再発現する。SPR/BLIのkinetics、交差反応性、細胞機能、発現・凝集を独立に測る。巨大libraryは希少配列へ到達する確率を上げるが、良い医薬品を保証しない。

抗原量を多くした初期roundは弱いbinderも残して多様性を守れるが、後半も同じ条件では差がつきにくい。反対に最初から厳しくすると、初期頻度の低い良好cloneがsamplingで消える。round数の多さも常に有利ではなく、増幅しやすい配列や一種類のepitopeを過度に優占させる。濃縮率と同時に、配列多様性がどう変化したかを読む必要がある。

### 5. 二つの無細胞系は目的に応じて選ぶ

ribosome displayはPCR-based diversificationと反復進化を組み合わせやすい。mRNA displayは共有結合の安定性と選択条件の自由度に優れるが、puromycin連結の最適化を要する。どちらも哺乳類細胞の分泌品質管理やIgG糖鎖を再現しない。無細胞系で広く濃縮し、yeast/mammalian displayや分泌IgG assayで発現・assembly・機能を絞る段階的workflowが合理的である。

## 図または比較表

```text
DNA library → 転写 → 無細胞翻訳 → 遺伝子型–表現型を連結
                                      │
          ribosome display：protein─ribosome─mRNA（非共有結合）
          mRNA display     ：protein─puromycin─mRNA（共有結合）
                                      ↓
      抗原で選択 → 洗浄 → 核酸回収 → RT-PCR → 次round／配列決定
```

| 観点 | ribosome display | mRNA display |
|---|---|---|
| 連結の本体 | protein–ribosome–mRNA三者複合体 | puromycinを介したprotein–mRNA共有結合 |
| library規模の目安 | 10^12〜10^14 | 10^12〜10^14 |
| 主な強み | 鋳型調製が直接的、mutagenesisと反復進化 | 複合体が安定、選択条件の自由度が高い |
| 主な制約 | ribosomeを保つ温和な条件が必要 | puromycin連結効率、RNA・RT工程のbias |
| 抗体format | 主にscFv、単鎖scaffold | 主にscFv、単鎖scaffold；Fabはペア保持に工夫 |
| 最終的に必要な確認 | 可溶性抗体でkinetics・specificity・developabilityを再測定 | 同左 |

## 論文を読むためのポイント

1. **実効library sizeは何か**：理論多様性ではなく、選択へ投入した連結済み分子数とcoverageを見る。
2. **連結方式と効率は何か**：ribosome複合体の安定化条件、またはpuromycin fusion形成率を確認する。
3. **抗体formatを保てるか**：scFvかFabか、H鎖・L鎖の対応がround後も維持されるかを読む。
4. **どの性質へ選択圧をかけたか**：抗原濃度、洗浄時間、off-rate競合、negative selectionを確認する。
5. **増幅biasを監視したか**：各roundの回収量、PCR cycles、input/output NGS、対照選択を見る。
6. **enrichmentをaffinityと同一視していないか**：独立発現後にSPR/BLIで`kon`、`koff`、`KD`を測ったかを確認する。
7. **最終formatで再現したか**：scFv hitをFab/IgGへ変換した後の結合、機能、発現、凝集を読む。

## 抗体×AIとの接続

各roundのNGS countは、多数配列に一度にlabelを付けられる魅力的なAIデータである。しかし`log(count_after/count_before)`は純粋なaffinity labelではなく、翻訳、folding、連結、選択、回収、PCRを通過した**条件付きenrichment**である。0 countも「非binder」とは限らず、初期頻度不足やsampling dropoutかもしれない。

学習データにはplatform、round、input count、抗原濃度、洗浄・競合条件、translation系、抗体format、PCR batchを保存する。未観測0にはpseudocountを機械的に足すだけでなく、検出限界として扱う。近縁配列をtrain/testへ分散させず、最終IgGで測ったkineticsを外部testにする。AIで次roundの配列を提案する場合も、enrichment最大化だけでなく、diversity、発現性、specificityを別目的として保つ必要がある。

## 重要用語（8語）

- **cell-free display**：細胞を介さず、無細胞翻訳でタンパク質とコード核酸を対応づける選択法。
- **ribosome display**：新生protein、ribosome、mRNAの三者複合体を選択粒子にする方法。
- **mRNA display**：puromycinを介して翻訳産物とmRNAを共有結合させる方法。
- **puromycin**：aminoacyl-tRNAを模倣し、新生polypeptideへ共有結合できる抗生物質。
- **genotype–phenotype linkage**：選ばれたタンパク質の性質を、そのコード配列へ帰属できる物理的対応。
- **effective library size**：連結・folding後、実際に選択へ参加できた異なる分子の規模。
- **off-rate selection**：競合条件などで解離の速いcloneを除き、遅い`koff`を選ぶ操作。
- **enrichment**：選択前後での配列頻度の増加。affinity以外の工程biasも含む。

## 理解確認問題2問と各問題の簡潔な模範回答

### 問1

ribosome displayとmRNA displayでは、タンパク質とmRNAの結びつきがどう異なり、それが選択条件へどう影響するか。

**模範回答：** ribosome displayはribosomeを介した非共有結合性の三者複合体なので、複合体を壊さない温和な条件が必要である。mRNA displayはpuromycinによる共有結合を使うため、一般により厳しい洗浄や広い条件を試しやすい。

### 問2

NGSで選択後に強く濃縮された配列を、高affinity抗体と直ちに結論できない理由を二つ挙げよ。

**模範回答：** 濃縮度にはaffinityだけでなく、翻訳・folding・連結・PCRの効率と非特異結合が影響する。また固相化や洗浄条件は`kon`・`koff`・avidityを混ぜるため、可溶性抗体のSPR/BLIで再検証が必要である。
