# Day 002：アミノ酸変異の物理化学

## 今日の問い

抗体配列の1残基を置換したとき、側鎖の電荷・疎水性・大きさの変化は、立体構造、抗原結合、溶解性へどのように伝わるのだろうか。

## 本文

### 1. 20種類の違いは「側鎖」にある

タンパク質を構成する標準アミノ酸は、共通の主鎖と、化学的性質が異なる側鎖（R基）をもつ。側鎖は大まかに、非極性、極性・非荷電、酸性、塩基性へ分類できる。この分類は暗記表ではなく、「水と接したいか」「電荷をもつか」「水素結合をつくれるか」「どれほどの空間を占めるか」を予測する入口である。水中で折りたたまれた球状タンパク質では、非極性側鎖は内部へ埋まり、極性・荷電側鎖は表面に出る傾向がある。ただし、抗原結合面では疎水性残基が溶媒に露出し、埋もれた荷電残基が塩橋をつくることもある。したがって「残基名だけ」で性質を決めず、三次元的位置まで見る必要がある。[NCBI Bookshelf](https://www.ncbi.nlm.nih.gov/books/NBK9879/)

### 2. 電荷はpHと周囲の環境で変わる

Asp（D）とGlu（E）は通常負、Lys（K）とArg（R）は通常正に帯電する。His（H）は生理的pH付近でプロトン化状態が変わりやすい。ここで「通常」と書くのは、側鎖の電荷がpHと局所環境に依存するためである。イオン化基では、概念的に pH と pKa の大小関係がプロトン化率を決める。タンパク質内部への埋没、近くの荷電基、溶媒への露出度はpKaをずらしうるため、配列上のK、R、D、Eの個数差だけを、そのまま実効電荷差とみなしてはいけない。[Zhou & Pang, 2018](https://doi.org/10.1021/acs.chemrev.7b00305)

たとえば表面のDをKへ置換するD→Kは、単純な中性化ではなく、理想化すれば電荷を−1から＋1へ反転させる。この変化は抗原上の相補的な電荷との引力を強める可能性がある一方、別の分子への非特異的結合、抗体同士の引力・斥力、pI、クロマトグラフィー挙動にも影響する。「正電荷を足せば溶解性が上がる」のような一方向の規則ではなく、局所的な電荷パッチと分子全体の電荷を分けて考える。

### 3. 疎水性と極性は、折りたたみと結合の両方を動かす

Leu（L）、Ile（I）、Val（V）、Phe（F）、Trp（W）などの非極性・芳香族側鎖は、水から隠れて密に詰まることでタンパク質コアの形成に寄与する。実験的変異をまとめた総説でも、疎水性相互作用と水素結合はいずれも安定化へ大きく寄与するが、その大きさは周囲の構造に強く依存すると整理されている。[Pace et al., 2014](https://doi.org/10.1016/j.febslet.2014.05.006)

内部の大きな疎水性残基をAla（A）のような小さい残基へ変えると、空洞が生じ、van der Waals接触が失われ、フォールドが不安定になることがある。逆に、表面へWやFを導入すると、抗原の疎水性ポケットとの接触面積が増えて親和性が上がる可能性があるが、抗体同士の自己会合や非特異的結合も増えうる。Ser（S）、Thr（T）、Asn（N）、Gln（Q）、Tyr（Y）は水素結合の供与体・受容体になりうるが、変異で水素結合を1本増やしたから必ず安定化するわけではない。結合前に水とつくっていた相互作用を切る脱溶媒和コストや、側鎖を固定するエントロピー損失も同時に起こるからである。

### 4. 大きさ・形・柔軟性も独立した軸である

化学分類が同じ残基同士でも交換可能とは限らない。Gly（G）は側鎖が水素だけで主鎖の自由度が大きく、Pro（P）は環状側鎖で主鎖の取りうる角度を強く制限する。そのためG↔Pの置換は、電荷や疎水性の差以上にCDRループの形を変えうる。芳香族残基Y、F、Wは平たい環をもち、抗原との面接触やπ相互作用に使われる。Y→Fなら大きさと芳香環はほぼ保たれるが、Yの水酸基が失われるので水素結合は消えうる。Cys（C）は2残基間で共有結合性のジスルフィド結合を形成できるため、保存されたCを安易に置換すれば免疫グロブリンドメイン全体の構造を壊しかねない。

### 5. 変異効果は「残基×位置×相手」で決まる

同じL→S置換でも、疎水性コアなら不安定化、溶媒露出面なら溶解性改善、パラトープなら抗原接触の消失という別々の結果になりうる。さらに、単一変異の効果は周囲の残基に依存し、複数変異の効果が単純な足し算にならないことがある。これをエピスタシスという。一般に、多くの変異はタンパク質安定性を下げる側へ偏るため、機能を改善する変異が、別の安定化変異によって補償される場合もある。[Tokuriki & Tawfik, 2009](https://doi.org/10.1016/j.sbi.2009.08.003)

抗体ではこの文脈依存性が親和性とdevelopabilityのトレードオフとして現れる。抗IL-13抗体CNTO607では、重鎖CDR3の疎水性ホットスポットが高親和性に重要だった。そこをAlaへ置換すると溶解性は約13 mg/mLから164 mg/mL超へ改善した一方、KDは18 pMから45,000 pM超へ悪化した。つまり疎水性残基の除去は「物性改善」でも「抗体全体の改善」とは限らない。[Wu et al., 2010](https://doi.org/10.1093/protein/gzq037) この例は、変異後に結合だけ、または溶解性だけを測るのでは不十分だと教える。

### 6. 1変異を読むための因果チェーン

論文で変異を見たら、まず野生型と変異型の側鎖について、①電荷、②疎水性・極性、③大きさ・形、④水素結合能、⑤主鎖柔軟性の差を書く。次に位置を、構造内部、溶媒露出面、VH–VL界面、CDR、抗原接触部位へ分類する。そこから「失われる相互作用」「新しく生じうる相互作用」「代替説明」を挙げ、最後に結合、発現、熱安定性、凝集、非特異的結合など、実際に測られた値と照合する。この順序を守れば、配列差から結果を言い切らず、検証可能な仮説として読むことができる。

## 論文を読むためのポイント

変異表記（例：Y33A）は「33番のTyrをAlaへ置換」を意味するが、抗体ではKabat、Chothia、IMGTなど番号付け法が異なるため、位置番号だけで別論文と対応づけない。重鎖か軽鎖か、CDRかframeworkか、番号体系は何かを確認する。次に、変異体と野生型が同じ抗体形式・同じassay条件で比較されているかを見る。alanine scanningは側鎖寄与を調べる有用な方法だが、Ala置換で失うものは一種類ではないため、「直接接触残基の証明」とは限らない。構造、単一変異、復帰変異、速度論、安定性測定を組み合わせているかを確認する。

## 抗体×AIとの接続

配列をone-hot表現にすると残基の同一性は保てるが、D→EがK→Wより物理化学的に近い、といった類似性は明示されない。そこで電荷、疎水性、体積、溶媒露出度などを特徴量にできる。ただし、配列由来の正味電荷や疎水性スコアだけでは、立体構造上のパッチやpKa変化を捉えにくい。protein language modelは大量の配列から文脈依存の表現を学び、アミノ酸の生化学的性質から二次・三次構造に関する情報まで内部表現に含みうることが示されている。[Rives et al., 2021](https://doi.org/10.1073/pnas.2016239118)

抗体変異効果モデルでは、入力表現だけでなく教師ラベルを確認する。親和性上昇を学習しても、安定性・溶解性・非特異的結合を測っていなければ、CNTO607型のトレードオフを見逃す。また同じ変異でも背景配列で効果が変わるため、ランダム分割で近縁抗体をtrain/testへ混ぜると、未知系列への一般化性能を過大評価しうる。

## 重要用語5〜8語

| 用語 | 意味 |
|---|---|
| 側鎖（R基） | アミノ酸ごとに異なり、電荷・疎水性・形などを決める部分 |
| プロトン化 | H⁺を受け取った状態。pHと局所環境により割合が変わる |
| pKa | あるイオン化基のプロトン化状態が切り替わる目安となる値 |
| 疎水性効果 | 非極性基が水への露出を減らす方向へ集まる効果 |
| 溶媒露出度 | 残基が水などの溶媒へどれほど接しているか |
| 塩橋 | 反対符号の荷電基間に生じる静電的相互作用 |
| alanine scanning | 残基を順にAlaへ置換して機能・結合への寄与を調べる方法 |
| エピスタシス | ある変異の効果が、他の変異や背景配列に依存すること |
