# Day 010：親和性とアビディティ

## 今日の問い

同じ抗原結合部位をもつFabとintact IgGを比べたとき、なぜIgGは抗原表面から外れにくく見え、その差を「affinityが上がった」と呼ぶと誤解を招くのだろうか。

## 本文

### 1. affinityは1対1、avidityは複数結合の総合効果

**affinity（親和性）**は、1つの抗原結合部位（パラトープ）と1つのエピトープの単価相互作用の強さであり、単純な1対1系では`KD = koff / kon`で表せる。一方、通常のIgGには同一特異性のFab腕が2本ある。抗原側にも同じエピトープが複数あり、両腕が結合できると、複数の単価相互作用を合わせた**avidity（総合結合力、多価効果）**が生じる。affinityが面ファスナーの「1接点の強さ」なら、avidityは「複数接点をもつ全体の外れにくさ」である。[NCBI Bookshelf](https://www.ncbi.nlm.nih.gov/books/NBK26884/)

avidityは抗体配列だけに固定された定数ではない。同じIgGでも、可溶性の単量体抗原には実質的に一価で結合し、抗原が並ぶ細胞表面には二価で結合しうる。「IgGのKD」とあれば、単価affinityか、配置依存のapparent KD（見かけのKD）かを確認する。

### 2. 二本目の腕はなぜ効くのか

二価結合を段階に分けると理解しやすい。

```text
遊離IgG → 片腕結合 → 両腕結合
             ↑          ↓
          完全解離 ← 片腕だけ解離
```

最初の腕の結合後、二本目の腕は抗原表面の近傍に拘束されるため、近くのエピトープに対する**実効局所濃度**が高くなる。両腕が結合した後に片腕が外れても、もう片腕がIgGをつなぎ止め、その間に外れた腕が再結合できる。IgG全体が溶液へ逃げるには両腕が外れた状態を経るため、観測される解離はFabより遅く、洗浄後も信号が残りやすい。[Erlendsson and Teilum, 2021](https://doi.org/10.3389/fmolb.2020.615565)

ただし、二本目の結合にはIgGの向きとヒンジ角度を制限する代償があり、2つのエピトープがFab腕の届く距離と向きに存在しなければならない。avidityは単価のkon・koffに加え、価数、エピトープ間隔、抗原の可動性、ヒンジの柔軟性、表面密度から生まれるため、affinityから一定倍率で換算できない。

例えば、同一パラトープのFabとIgGを抗原低密度面で比べると、二価結合できず、解離の差は小さいかもしれない。高密度面ではIgGだけが二価化し、見かけの解離相が大きく遅くなりうる。この差はIgGの接触残基が改善した証拠ではなく、第二結合が可能になった証拠である。なお「両腕が同時に外れなければならない」は直感的な略記であり、実際には片腕結合状態と両腕結合状態を往復し、片腕状態から再結合より先に残る腕が外れたとき完全解離する。

### 3. 「二価」と「協同性」を混同しない

二本目が結合しやすくなる現象をcooperativityと呼ぶ文献もあるが、ヘモグロビンのような**アロステリック協同性**とは区別する。IgGでは、一方の結合がもう一方のパラトープを必ず高親和性型へ変えるのではなく、空間的拘束と局所濃度上昇で結合確率が上がる場合が多い。

両腕は同じ多量体抗原に結合することも、細胞膜上の別々の抗原を架橋することもある。後者は抗原のクラスター化や受容体シグナルを変えうるので、avidityは測定上の人工物だけでなく抗体機能そのものでもある。IgMも多数の結合部位により、各部位のaffinityが低くても多価抗原に高いavidityを示せる。[Oostindie et al., 2022](https://doi.org/10.1038/s41573-022-00501-8)

### 4. 実験値をaffinityと呼べる条件

単価affinityには、FabまたはscFvと単量体抗原を使うのが明快である。intact IgGを使うSPRでは、IgGを低密度に固定して単価抗原を流す配置が二価結合を抑えやすい。逆に、高密度固定抗原へIgGを流すと、表面再結合と二価結合で見かけのkoffが小さくなり、1:1 fitが滑らかでも単価KDとは限らない。[Moroz and Brooks, 2024](https://doi.org/10.1089/mab.2024.0019)

IgGとFab、抗原固定化密度、単量体と多量体抗原を比較し、十分な解離時間と元曲線・残差を確認する。同じIgGで抗原密度だけを変えてapparent KDが変われば、配列由来のaffinity差よりavidityを疑う。細胞結合やELISAのEC50も抗原量、二価結合、検出系を含む応答値であり、KDへ読み替えられない。

血清のavidity assayでは、結合後に尿素やチオシアン酸塩を加え、処理後と未処理の信号比を**avidity index**とすることがある。これは相対指標であり、変性剤濃度、洗浄時間、抗原、抗体混合物に依存するため熱力学的KDではない。[Pullen et al., 1986](https://doi.org/10.1016/0022-1759(86)90268-1)

### 5. 高いavidityは目的に合うときだけ価値がある

細胞表面抗原やウイルス粒子へ長く留まる目的では、avidityは低い単価affinityを補える。低密度では一価、高密度でのみ二価結合する設計なら標的密度を識別に利用できる。一方、強い多価結合は正常組織への滞留、組織内拡散の低下、意図しない受容体クラスター化にもつながる。「最も外れにくい候補」ではなく、標的の密度・配置と望む作用機序に合う候補を選ぶ。

また、単価affinityを極端に高めると低密度の正常細胞にも一価のまま長く結合し、密度による選択性を失う可能性がある。抗体工学では「各腕を最強にする」以外に、単価affinityを適度に保ち、多価標的でだけavidityを獲得させる設計思想も重要である。

## 図または比較表

| 観点 | affinity | avidity |
|---|---|---|
| 基本単位 | 1パラトープ対1エピトープ | 複数の単価相互作用の総合効果 |
| 主な決定因子 | 接触残基、kon、koff | 単価affinity＋価数・密度・間隔・柔軟性・再結合 |
| 代表的な測定 | Fab–単量体抗原のSPR/BLI | IgG–多価抗原、細胞結合、avidity index |
| 値の表し方 | 条件を明記したKD | apparent KD、見かけのkoff、相対的indexなど |
| 抗原密度の影響 | 理想的単価系では小さい | 二価結合の成立率が変わるため大きい |
| 解釈 | 1接点の強さ | 分子全体が実環境でどれだけ外れにくいか |

## 論文を読むためのポイント

1. 著者が`affinity`と呼ぶ値は、Fabの単価KDか、intact IgGのapparent KDか。
2. 抗原は単量体・多量体・固相・細胞表面のどれで、密度と固定化方向は示されているか。
3. IgGとFab、または複数の抗原密度で測定し、avidityを切り分けているか。
4. 小さい見かけのkoffを、再結合や測定時間の限界を除かずに配列の効果としていないか。
5. avidity index、EC50、KDを同じ「強さ」の尺度として混同していないか。
6. 二価結合の差が、機能アッセイや標的密度依存性と整合しているか。

## 抗体×AIとの接続

AIで結合性を学習するとき、Fabの単価KDとIgGのapparent KDを同じラベル列へ混ぜると、同一パラトープに矛盾する教師値が付く。抗体フォーマット、価数、抗原の多量体状態、表面密度、固定化方向、assay、fitモデルをprovenanceとして保持し、`monovalent affinity`と`avidity-dependent binding`を別タスクにする必要がある。avidity予測には配列だけでなく、IgG幾何、エピトープ間距離、抗原密度・可動性などの文脈入力が必要である。逆にこの文脈依存性を利用すれば、「高発現標的では二価結合し、低発現正常細胞では外れる」ような密度選択性を、多目的設計やactive learningの目的にできる。

## 重要用語5〜8語

- **affinity（親和性）**：1つのパラトープと1つのエピトープの単価結合の強さ。
- **avidity（総合結合力）**：複数の結合部位が作る相互作用全体の外れにくさ。
- **valency（価数）**：1分子が同時に形成できる特異的結合部位の数。
- **実効局所濃度**：第一結合で拘束された第二の結合部位が、近傍の相手に対して感じる高い局所濃度。
- **rebinding（再結合）**：一度外れた結合部位が、分子全体の拡散前に近傍の相手へ再び結合すること。
- **apparent KD**：多価性や実験配置を含むモデルから得た条件依存の見かけの解離定数。
- **avidity index**：変性剤処理後に残る結合信号などから算出する相対的なavidity指標。

## 理解確認問題2問と各問題の簡潔な模範回答

### 問1

同じパラトープをもつFabとIgGで、抗原高密度表面に対するIgGの見かけのkoffが100倍小さかった。この結果だけから、IgGの各Fab腕のaffinityが100倍高いと言えるか。

**模範回答：** 言えない。IgGでは片腕が外れても他方が表面につなぎ止め、再結合によって分子全体の解離が遅く見えるため、単価affinityはFab–単量体抗原系で評価する必要がある。

### 問2

同じIgGが抗原低発現細胞より高発現細胞へ著しく強く結合した。avidityの観点から、まず検証すべき説明を1つ挙げよ。

**模範回答：** 高発現細胞ではFab腕の到達範囲内に複数の抗原があり、二価結合が成立した可能性を検証する。IgGとFabの差や、抗原密度系列に対する結合・解離を比べると切り分けやすい。

## さらに調べる疑問2〜3問

1. IgGのヒンジ長と柔軟性は、結合可能なエピトープ間距離をどう変えるか。
2. 抗原密度を連続的に変えたとき、二価結合が急に優勢になる閾値をどう測定・モデル化できるか。
3. 二重特異性抗体では、2種類の単価affinityをどう組み合わせて正常細胞と標的細胞を識別するか。

## 自分の3行要約

- affinityは1接点の強さ、avidityは複数接点と再結合から生じる分子全体の外れにくさである。
- IgGの二価結合にはエピトープの密度・間隔・向きが必要で、同じIgGでも相手と配置によりavidityが変わる。
- 論文やAIデータでは、Fabの単価KDとIgGのapparent KD・avidity indexを分けて扱う。
