# Day 050：検出限界と打ち切り値を正しく扱う

## 今日の問い

抗体assayの結果が「検出せず」「< LLOQ」「> ULOQ」「欠測」と記録されたとき、それらを0や同じ数値として扱うと、比較やAI学習にどのような誤りが生じるだろうか。

## 本文

### 1. 「測れない」と「存在しない」は違う

抗体assayには、信頼して数値を報告できる範囲がある。低濃度ではsignalがblankの揺らぎに埋もれ、高濃度では検出器や標準曲線が飽和する。したがって「測定値なし」は、抗原・抗体・活性がないことを意味しない。真値が範囲外なのか、試料を失ったのか、runが不成立だったのかを分けて考える。

**検出限界（LOD／DL）**はanalyteをblankから識別できる最小量で、正確な定量を保証しない。**定量限界（LOQ／QL）**は許容できるaccuracyとprecisionで定量できる下限である。ICH Q2(R2)は、背景応答の標準偏差を`σ`、検量線の傾きを`S`として`DL = 3.3σ/S`、`QL = 10σ/S`という推定法を示す[1]。ただし式だけで決めず、既知濃度試料を実際のmatrixと手順で測り、下限付近の性能を確認する。

bioanalysisでは、検量線上の定量下限・上限を**LLOQ**、**ULOQ**と呼ぶ。ligand-binding assay（LBA）の応答はしばしばS字型なので、この範囲内だけを濃度へ逆算する。ICH M10ではLBAのLLOQ／ULOQでaccuracyとprecisionを検証し、範囲外のanchor pointを定量可能値として扱わない[2]。限界はkit固有の数字ではなく、matrix、希釈、試薬lot、装置、受入基準を含む測定手順の属性である。

### 2. 打ち切りは「一部が分かる」観測である

結果が`< 0.1 ng/mL`なら、真値は不明でも0.1未満だと分かる。これは**左打ち切り**である。`> 100 ng/mL`は下限だけが分かる**右打ち切り**である。一方、装置停止、試料喪失、sample ID不明、QC不合格によるrun棄却では値の範囲も分からず、**欠測**となる。打ち切りと欠測を同じ`NA`に潰してはいけない。

打ち切りは**切断**とも違う。打ち切りでは対象sampleが存在し、限界外だと記録される。切断では限界外のsample自体がdatasetに入らない。「signalが出たcloneだけ保存」したscreening datasetでは、non-binderの数さえ見えず、対象集団が選択後の集団へ変わる。

LLOQ未満をすべて0、LLOQ、LLOQ/2などへ置換すると、人工的に同じ値が並び、平均、分散、相関、順位が変わる。免疫学的測定のsimulationでは、単一値置換は分散を過小評価し、削除は回帰係数を偏らせ得た[3]。低親和性cloneほど測定不能なら、測れたcloneだけの解析は強いbinderへ偏る。

### 3. まず実験側で範囲外を減らし、経緯を残す

ULOQ超なら、検証済みの希釈率で再測定し、希釈補正後の濃度を得る。LBAは測定範囲が狭く、高濃度analyteでsignalが逆に低下する**hook effect**もあるため、高濃度試料と希釈直線性を検証する[2]。低値が重要なら、sample量、検出抗体、増幅法、標準曲線を見直し、目的に合うLLOQを設定する。

再測定理由と最終値の採用規則は結果を見る前に決める。期待と違う値だけ再測定すればbiasになる。ICH M10は、再測定sample、初回値、理由、再測定値、採用値と根拠の記録を求める[2]。raw signal、希釈率、calibration curve、QC成否、run ID、各limit、`<`や`>`のqualifier、欠測理由を保存すれば、後から適切な解析を選べる。

### 4. 解析と論文読解では「なぜ見えないか」を問う

欠測は便宜上、**MCAR**（観測値・未観測値と無関係）、**MAR**（観測済み情報で条件づければ未観測値と無関係）、**MNAR**（それでも未観測値に依存）として考える[4]。偶発的な故障はMCARに近いことがあるが、低signalゆえLLOQ未満になる現象は値そのものに依存する。機序はdatasetだけでは確定できず、実験知識と感度解析が必要である。

まず打ち切り・欠測の件数と割合を群別に示す。連続値なら、打ち切りを明示する尤度、Tobit型回帰、maximum likelihood、multiple imputationなどが候補になる[3,5–7]。選択は打ち切り割合、分布、sample size、目的に依存するため、仮定を書き、別の扱いでも結論が保たれるか確かめる。

抗体データでは、測定対象によって限界の現れ方も違う。ELISAで抗原濃度を定量する場合は標準曲線の上下限、SPRで速度論を測る場合は装置応答だけでなく、速すぎる解離、mass transport、curve fitの成否が報告可能な`kon`、`koff`、`KD`を制約する。細胞assayのEC50は、最大反応に達しなければ単に「弱い数値」ではなく、曲線から識別できないparameterかもしれない。元のsignalとfitの品質を見ず、最終的な1個の数値だけを集めると、測定不能と低活性を混同する。

候補100 cloneのうちKDが20 cloneだけなら、残り80 cloneがnon-binder、curve fit不良、範囲外、発現不良、未測定のどれかで主張は変わる。`KD > 1 µM`は「1 µM」という値ではなく、真値への制約である。論文では軸の範囲、LOD／LLOQ／ULOQ、範囲外点、除外数、再測定規則、全候補を分母とした成功率を探す。「何が、なぜ見えなかったか」も測定結果の一部である。

群間比較では、打ち切り率そのものも結果として読む。たとえば対照群の5%に対して処置群の60%がLLOQ未満なら、処置によりsignalが低下した可能性は高いが、LLOQ未満でどれほど違うかは直接分からない。置換後の平均値だけを比較するより、「定量可能割合」と「定量範囲内の分布」を分けて示し、limitの設定を変えた感度解析を添える方が、測定系が支える主張の範囲を明確にできる。

## 図または比較表

```text
数値が報告されない
   ├─ 測定限界との関係が分かる
   │    ├─ < LLOQ / < LOD → 左打ち切り（上限は既知）
   │    └─ > ULOQ         → 右打ち切り（下限は既知）→ 検証済み希釈で再測定
   └─ 値の範囲も分からない
        └─ 装置故障・試料喪失・run棄却 → 欠測（理由を記録）
```

| 表記・状態 | 分かっていること | 避けたい処理 | 優先する対応 |
|---|---|---|---|
| `ND` / `< LOD` | blankと区別できない | 0＝不存在と断定 | LODとraw signalを保存 |
| `< LLOQ` | 真値は下限未満、定量精度不足 | LLOQ/2へ機械的置換 | 左打ち切りとして解析 |
| `> ULOQ` | 真値は上限超 | ULOQへ丸める | 検証済み希釈で再測定 |
| QC不合格・故障 | 値の範囲も不明 | 範囲外値と混同 | 欠測理由とrunを記録 |
| 選択後のみ測定 | 未選択sampleはdataset外 | 測定済みだけで一般化 | 選択過程と全分母を示す |

## 論文を読むためのポイント

1. **限界の定義**：LODとLLOQを区別し、算出法、単位、matrix、accuracy／precision基準が示されているか。
2. **報告可能範囲**：検量線、LLOQ、ULOQ、希釈率、範囲外sampleの再測定法がMethodsにあるか。
3. **記号の意味**：`0`、`ND`、`BLQ`、`<`、`NA`がそれぞれ何を表し、元のqualifierが保持されているか。
4. **分母**：測定した全sample数、除外数、打ち切り数・割合が群別に示されているか。
5. **解析仮定**：削除・代入・censored modelの選択理由と、別の扱いによる感度解析があるか。
6. **選択バイアス**：発現、予備screening、curve fitの成功が精密測定への選抜条件になっていないか。

“Values below the LLOQ were set to zero” とあれば、低値群の平均・分散が人為的に変わり、群差や相関が代入規則に依存していないかを疑う。

## 抗体×AIとの接続

LLOQ未満を0、ULOQ超を上限値として教師labelにすると、本来は順序制約しかない値を正解値に変えてしまう。モデルは抗体配列と生物学の関係だけでなく、assayのレンジや置換規則を学習する。さらに、curve fitに成功したcloneだけを残すと、低発現・低親和性・速い`koff`のcloneが消え、test setにも同じselection biasが入る。

datasetには`value`だけでなく、`qualifier`（`=`, `<`, `>`）、limit、unit、assay、run、希釈率、QC、欠測理由を別列で保存する。学習時は打ち切りを考慮したlikelihoodや区間label、検出可否と定量値を分けるmulti-task設計が候補になる。評価は測定可能なsubsetだけでなく、打ち切り率、範囲内での誤差、限界をまたぐ分類性能を報告し、assayごとのlimit差がtrain/test分割と交絡していないか確認する。

## 重要用語（8語）

- **LOD／DL（検出限界）**：analyteをblankから識別できる最小量。正確な定量を保証しない。
- **LLOQ（定量下限）**：許容されたaccuracyとprecisionで定量できる最小濃度。
- **ULOQ（定量上限）**：許容されたaccuracyとprecisionで定量できる最大濃度。
- **報告可能範囲**：十分なaccuracy、precision、responseを満たして結果を報告できる区間。
- **左打ち切り**：真値が既知の下限より小さいが、正確な値は不明な観測。
- **右打ち切り**：真値が既知の上限より大きいが、正確な値は不明な観測。
- **欠測**：測定失敗や試料喪失などで、値やその範囲を観測できない状態。
- **hook effect**：analyteが過剰なためLBAのsignalが抑制され、高濃度を低く見誤る現象。

## 理解確認問題2問と各問題の簡潔な模範回答

### 問1

ELISAで`< 0.2 ng/mL`と報告された5試料をすべて0としてよいか。

**模範回答：** よくない。各真値は0とは限らず「0.2 ng/mL未満」という左打ち切り情報を持つ。限界とqualifierを保持し、目的に応じたcensored modelや感度解析を選ぶ。

### 問2

ある抗体試料が`> ULOQ`だった。ULOQをその試料の濃度として記録すべきか。

**模範回答：** 記録すべきでない。分かるのは真値がULOQを超えることだけである。可能なら検証済みの希釈条件で再測定し、元の範囲外結果と再測定理由も残す。
