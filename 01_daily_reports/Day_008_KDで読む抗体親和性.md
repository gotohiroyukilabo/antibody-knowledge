# Day 008：KDで読む抗体親和性

## 今日の問い

抗体AのKDが10 nM、抗体Bが100 nMと報告されたとき、なぜAの方が高親和性と言え、その比較が成立するために何を確認すべきだろうか。

## 本文

### 1. affinityを「平衡の偏り」として捉える

抗体の**affinity（親和性）**は、1つの抗原結合部位と1つのエピトープの結びつきやすさである。最も単純な1対1結合では、抗体の結合部位をAb、抗原をAg、複合体をAbAgとして、次の可逆反応を考える。

\[
Ab + Ag \rightleftharpoons AbAg
\]

分子は結合と解離を繰り返すが、十分に時間がたつと、各成分の濃度が平均として変化しない**平衡**に達する。このときの平衡解離定数は、

\[
K_D=\frac{[Ab]_{free}[Ag]_{free}}{[AbAg]}
\]

で定義され、通常はM、nM、pMなど濃度の単位で表す。角括弧は平衡時の濃度、`free`は複合体になっていない分子を意味する。IUPACもKDをこの濃度比として定義している。分母の複合体が相対的に多いほどKDは小さくなるため、**小さいKDほど高いaffinity**を表す。[IUPAC Gold Book](https://doi.org/10.1351/goldbook.14132)

ここで「小さいほど強い」は、KDが解離側の平衡定数だからである。結合定数KAを使う論文では、単純系なら`KA = 1/KD`なので大きいほど強い。記号の添字と単位を見ずに大小だけを比べると、結論を逆にしてしまう。

### 2. KDは半分が結合する濃度なのか

抗原が抗体より十分過剰で、1対1・非協同的な結合を仮定すると、占有率θは次式になる。

\[
\theta=\frac{[Ag]_{free}}{K_D+[Ag]_{free}}
\]

したがって、遊離抗原濃度がKDに等しいときθは0.5、つまり抗体結合部位の半分が占有される。KD = 10 nMなら、遊離抗原1 nMで約9%、10 nMで50%、90 nMで90%が結合する計算である。これはKDを直感化する有用な見方だが、**加えた抗原の総濃度**が常にKDで半占有になるという意味ではない。

抗体濃度がKDに比べて無視できないと、結合によって抗原が消費され、総濃度と遊離濃度の差が大きくなる。このligand depletion条件で単純な双曲線を当てはめるとKDを誤推定しうるため、物質収支を含む二次方程式でfitするか、測定濃度を設計し直す必要がある。また、測定点がすべてKDよりはるかに低ければ曲線の立ち上がりしか見えず、すべて高ければ飽和部しか見えない。KDの上下をまたぐ濃度系列と、飽和値・非特異的結合を定める対照が必要である。[Jarmoskaite et al., 2020](https://doi.org/10.7554/eLife.57264)

KDは数桁にわたるため、差は引き算より比で読む。2つの抗体の結合自由エネルギー差は、同じ温度・標準状態なら概念的に`ΔΔGbind = RT ln(KD,A / KD,B)`で結ばれる。25°CではKDの10倍差が約5.7 kJ/molの差に相当する。これは少数の非共有結合の組み替えでも生じうる大きさであり、点変異がKDを桁単位で変える理由を物理量として考える助けになる。ただし、KDが10倍改善しても細胞応答や薬効が必ず10倍になるわけではない。

### 3. 数値は「抗体だけの性質」ではない

KDは抗体名に固定された絶対値ではなく、**抗体–抗原の組合せと測定条件**の値である。抗原の構築物や立体構造、抗体フォーマット、pH、塩濃度、温度、固定化方向が変われば、接触面の電荷、分子運動、利用可能なエピトープが変わり、測定値も変わりうる。よって「抗体Aは10 nM」と単独で書くより、「Fabと単量体抗原を25°C・特定bufferで測定したKDが10 nM」と記録する方が再現可能である。

平衡測定では、各濃度で本当に平衡へ達したかも重要である。高親和性で解離が遅い相互作用は、短いincubationでは平衡前の信号を読んでしまう。異なるincubation時間で同じ値に収束するかを確認する、または速度論測定から必要時間を見積もる。Jarmoskaiteらは100報の結合測定を調査し、適切な時間・濃度範囲を確立する対照が多くの研究で十分に記載されていないと報告した。fitが滑らかでも、仮定が満たされなければ正しいKDとは限らない。

### 4. IgGでは「1対1」の前提が崩れやすい

IgGには通常2本のFab腕がある。表面に抗原が高密度で並ぶと、一方の腕が外れても他方がつながったままになり、近傍の抗原へ再結合しやすい。その結果、単一結合部位のaffinityより強い**avidity（多価結合の総合効果）**が観測される。固相ELISAや細胞表面結合で得た見かけのKDを、可溶性Fabの単価KDと同列に比較してはいけない。

単価affinityを測るにはFabやscFvと単量体抗原を使う、またはIgGを低密度で固定して単価抗原を流すなど、二価結合を抑える配置を選ぶ。近年の抗体測定ガイダンスも、可能なら単価断片を用い、平衡法では平衡到達を実証するよう勧めている。[Moroz and Brooks, 2024](https://doi.org/10.1089/mab.2024.0019) なお、avidityは実際の細胞上で重要な機能になりうるため「誤差」ではない。知りたい対象が単価affinityなのか、実環境での総合的な結合なのかを先に決める。

### 5. KDが答えること・答えないこと

KDは平衡でどちら側が有利かを要約するが、そこへ至る速さは一意に示さない。単純な1対1モデルでは`KD = koff / kon`なので、同じKDでも速く結合して速く外れる抗体と、遅く結合して遅く外れる抗体がありうる。速度論はDay 9で扱う。また、高affinityでもエピトープが細胞上で隠れている、標的が急速にinternalizeする、結合しても機能を阻害しない、といった場合には高い薬効を保証しない。KDは重要な物理量だが、EC50、IC50、細胞機能、特異性の代用品ではない。

## 図または比較表

| 観測・表記 | 1対1平衡での意味 | 読むときの注意 |
|---|---|---|
| KD = 1 nM | KD = 100 nMより複合体側へ偏る | 同じ抗原・条件・フォーマットで比較する |
| `[Ag]free = KD` | 結合部位の占有率が50% | 総抗原濃度とは限らない |
| KAが大きい | `KA = 1/KD`なので高親和性 | KDとの記号混同に注意 |
| IgGの見かけのKD | 二価結合を含む場合がある | 単価affinityかavidityか確認する |
| KD = koff/kon | 平衡値を2つの速度定数で表す | 同じKDでも速度論は異なりうる |

```text
遊離 Ab + Ag  ⇄  複合体 AbAg
       ↑              ↑
   KDが大きい      KDが小さい
   解離側へ偏る    結合側へ偏る
```

## 論文を読むためのポイント

1. KD、KA、EC50、IC50のどれを報告しているか、値と単位を確認する。
2. 抗体はFab・scFv・IgGのどれか、抗原は単量体か多量体か、固定化密度はどうかを見る。
3. 1対1モデル、平衡到達、遊離濃度近似、濃度範囲というfitの前提を確認する。
4. 数値だけでなく、元の滴定曲線、反復、誤差、非特異的結合対照、測定上限・下限を見る。
5. 異なるassay間のKD差を、抗体配列の差だけで説明していないか注意する。

## 抗体×AIとの接続

KDを教師ラベルにするなら、まず全値をMへ換算し、`pKD = -log10(KD [M])`や`log10 KD`へ変換すると桁差を扱いやすい。pKDでは1 nMが9、100 nMが7となり、**高いほど高親和性**なので向きも明記する。`KD < 1 nM`のような検出限界による値は1 nMという点ではなく打ち切りデータである。さらに、抗体・抗原配列、フォーマット、測定法、温度、pH、固定化配置、単価か見かけ値かをprovenanceとして保持する。条件の異なるKDを一列に混ぜると、モデルは配列–affinity関係ではなくassay差を学習しかねない。高スループット滴定は配列–KD地形を作れるが、発現量と結合信号の分離、測定可能範囲外の扱いが不可欠である。[Adams et al., 2016](https://doi.org/10.7554/eLife.23156)

## 重要用語5〜8語

- **結合平衡**：結合と解離が続きながら、平均濃度が変化しない状態。
- **KD（平衡解離定数）**：遊離分子と複合体の平衡比。小さいほど高親和性。
- **KA（平衡結合定数）**：単純系ではKDの逆数。大きいほど高親和性。
- **占有率（fractional occupancy）**：全結合部位のうち抗原が結合した割合。
- **遊離濃度**：複合体を形成していない分子の濃度。
- **ligand depletion**：結合により遊離ligandが総添加量より大きく減る状態。
- **affinity**：1つの結合部位と1つの相手との単価の結合強度。
- **avidity**：複数の結合を合わせた総合的な結合強度。

## 理解確認問題2問と各問題の簡潔な模範回答

### 問1

同じ条件で測った抗体AのKDが2 nM、抗体Bが40 nMだった。どちらが高親和性で、何倍の差と表現できるか。

**模範回答：** Aの方が高親和性である。KDは小さいほど強く、40 ÷ 2 = 20なので、平衡定数の比としてAはBより20倍高いaffinityをもつと表現できる。

### 問2

固相化した多量体抗原へintact IgGを結合させて得たKDを、Fabの単価KDとそのまま比較できないのはなぜか。

**模範回答：** IgGの2本の腕が同時または連続的に結合し、avidityで見かけの解離が遅くなる可能性があるためである。単価断片または二価結合を抑えた配置で測るか、値をapparent KDと明示する。

## 自分の3行要約

- KDは1対1結合の平衡が遊離側と複合体側のどちらへ偏るかを表し、小さいほど高親和性である。
- `[Ag]free = KD`で半占有になるのは単純モデルの条件下であり、濃度設計と平衡到達を確認する。
- 抗体フォーマットとassay条件を記録し、単価affinityと多価avidityを区別して論文やAIデータを読む。
