# Day 075：熱安定性と変性経路

## 今日の問い

抗体候補AのTmが候補Bより高ければ、Aの方が保存中に凝集しにくいと判断してよいだろうか。IgGのどの部分が、どの順序で構造を失い、その後どの経路で凝集するのかを測定値からどう読み解くのか。

## 本文

### 1. 構造安定性には熱力学と速度論の二つの見方がある

抗体の**構造安定性（conformational stability）**とは、天然状態の立体構造を保つ傾向である。単純な二状態モデル `N ⇄ U` では、天然状態Nと変性状態Uの自由エネルギー差 `ΔG = G_U − G_N` が大きいほど、ある温度でNが優勢になる。しかし多ドメインのIgGは、しばしば `N → 部分変性状態I → 凝集体A` と進む。Iが凝集して系から除かれると逆反応を測れず、熱転移には加熱速度や凝集速度も影響する。

理想的な可逆二状態転移でのTmは、NとUの存在比が等しくなる温度であり、室温での`ΔG`そのものではない。二つの抗体のTmが同じでも、変性enthalpyや熱容量差が違えば、保存温度でのNの割合や温度依存性は異なり得る。抗体ではさらに複数転移が重なるため、Tm一個への要約には情報損失がある。

つまり安定性には、構造が崩れにくいという熱力学的側面と、変性・凝集が一定時間内に進みにくいという速度論的側面がある。保存温度がTmより低くても、少数のIが数か月かけて蓄積すれば品質は低下する。ICH Q5Cも、単一試験ではなく、純度、分解物、生物活性などを組み合わせ、実時間・実保存条件で評価するよう求めている[1]。

### 2. IgGの熱変性は一つの「融解」ではない

IgGはFab、CH2、CH3など複数の協同的単位を持つため、DSC曲線には二つまたは三つの重なった転移が現れ得る。IgG1ではCH2が低温側、FabとCH3が高温側へ寄ることが多いが、固定規則ではない。可変領域がFabを不安定化すると、FabがCH2とともに最初の転移へ含まれる。Ionescuらは、同じヒトgermline由来でもFabの見かけのTmが異なり、温度だけでなく変性enthalpyやFab/Fc断片との比較がピーク割当てに重要だと示した[2]。

17種のヒトまたはヒト化IgGでは、Fab転移のTmが57〜82°Cに広がり、低いFab安定性は低発現や凝集と関連した[3]。CDR graftingや親和性成熟は結合を改善しても、疎水性core、VH–VL界面、turn、ジスルフィド周辺を乱し得る。Fc側もサブクラス、ジスルフィド配置、糖鎖、pHで変わるため、「Tm1＝常にCH2」と機械的に読んではならない。

ピーク割当てには、intact IgGだけでなく単離Fab/Fc、可能なら各ドメインの測定を重ねる。ピーク面積に対応する熱量、変異で移動したピーク、円二色性や赤外分光による二次構造変化も手掛かりになる。複数ピークが近いと一つに見えるため、曲線全体と解析モデルも確認する。

### 3. Tm、Tonset、Taggは異なる観測量である

**DSC**は加熱時の過剰熱容量を測り、ピーク温度付近をTmとする。**nanoDSF**は主にTrp周辺環境の変化を内因性蛍光比から追い、**色素DSF**は疎水面の露出に伴う色素蛍光を追う。原理が違うため、同じ試料でも値は一致しないことがある。多ドメイン・凝集性タンパク質では転移が重なり、単一の変曲点へ要約すると不安定ドメインを見落とし得る[4]。

**Tonset**は構造変化の検出開始、**Tm**は転移の中点またはピーク、**Tagg**は光散乱などで会合が検出され始める温度である。Taggは装置閾値、濃度、加熱速度に依存し、物質固有の定数ではない。Tmより前に会合が見える場合も、両者がほぼ同時の場合もある。DSFとDSCには相関があった一方、DSFのTmは平均約3°C低く、界面活性剤は色素蛍光を妨げたとの報告もある[5]。数値は手法と条件をそろえて比較する。

例えばTmが上がってもTaggが下がったなら、単分子のfoldingは強まった一方、分子間反発や界面挙動が悪化した可能性がある。逆にTaggだけ高くても、測定時間内に大粒子が生じなかっただけかもしれない。温度値の大小だけでなく、蛍光と散乱の立ち上がる順序を経路の仮説として読む。

### 4. 変性経路と凝集経路は一対一ではない

加熱で生じたIでは内部の疎水面などが露出し、分子間会合の核になりやすい。IgGの熱変性研究では、低温側ではunfoldingが律速だが、高温側ではIが増え、完全変性前に凝集へ固定される経路が示された[6]。再加熱で同じ曲線を再現できないなら、Tmは平衡定数ではなく`apparent Tm`と解釈する。

ただし最初に変性するドメインが凝集の起点とは限らない。IgG2のDSCとSECの比較では、最も不安定なドメインが最も凝集しやすいとは限らず、凝集体中にも折りたたまれたドメインが残った[7]。撹拌、凍結融解、容器界面も熱screenとは別経路を取り得る。高いTmやTaggだけでは、保存中の単量体減少、粒子形成、活性低下を保証できない。

凝集生成物にも、可逆的二量体、可溶性高分子種、サブビジブル粒子、沈殿があり、互いに同義ではない。SECは主に可溶性分子種、光遮蔽や画像法はより大きな粒子を見る。変性経路を結論するには、異なるサイズ範囲と原理を持つ測定を組み合わせる必要がある。

### 5. 候補比較では「曲線・条件・時間」をセットで読む

初期screenでは抗体濃度、buffer、pH、加熱速度をそろえ、Tm1だけでなく全ピーク、Tonset、散乱曲線を残す。次に予定製剤に近い条件で実時間・加速保存、凍結融解、撹拌を行い、SEC、粒子法、構造、結合・potencyを直交的に測る。8種の開発可能なIgGでは、熱転移profileが幅広くても製剤最適化で長期安定化でき、最初のTonset/TmよりFab転移の改善が有用な場合が示された[8]。

配列engineeringでは低安定性ピークを断片測定や変異で特定し、結合界面を避けたframework修復、異常Cysや埋もれた荷電残基の修正を検討する。製剤側ではpH、buffer、塩、糖、界面活性剤をscreenする。ただしTmを上げる処方がTagg、長期単量体率、粘度、活性も改善するとは限らない。最終判断は分子、製剤、濃度、容器、保存期間を明示した使用条件で行う。

実務では、まず共通条件で候補の相対順位を取り、次に各候補で製剤条件を最適化し、最後に実際の容器と投与濃度で確認する。段階が違うデータを一列に並べず、「候補固有の弱点」と「製剤で救済できる弱点」を分けると、配列を改変するか処方を変えるかの判断が明確になる。

## 図または比較表

```text
天然状態 N ──可逆的な局所ゆらぎ──> 部分変性状態 I
    ↑                                  │
    └────────再フォールディング────────┘
                                       ├─核形成・成長─> 可溶性凝集体／粒子
                                       └─化学変化・界面吸着─> 別の不可逆経路

DSC / nanoDSF：主に N → I の構造転移
光散乱：主に会合開始（Tagg）　SEC / 粒子法：生成物を測定
```

| 指標・手法 | 主な観測対象 | 候補比較での用途 | 読むときの注意 |
|---|---|---|---|
| DSCのTm・enthalpy | 熱容量変化、協同的転移 | ドメイン転移と製剤差 | ピーク重複、不可逆性、scan rate |
| nanoDSFのTm | Trp周辺環境の変化 | 少量・高throughput screen | Trp位置、散乱、曲線解析に依存 |
| 色素DSF | 疎水面露出 | buffer・添加剤screen | 色素や界面活性剤の干渉 |
| Tagg・光散乱 | 粒径／散乱の増加開始 | 加熱中の会合検出 | 濃度、閾値、加熱速度に依存 |
| SEC・粒子法・potency | 保存後の生成物と機能 | 製品としての安定性確認 | 一つの方法では全サイズを覆えない |

## 論文を読むためのポイント

1. **安定性の定義**：Tm、Tonset、Tagg、保存後単量体率、残存活性のどれを結論に使ったか。
2. **ピークの割当て**：Tm1をCH2と仮定しただけか、Fab/Fc断片、enthalpy、変異で検証したか。
3. **測定条件**：抗体濃度、pH、buffer、添加剤、加熱速度、装置、解析閾値が比較群で同じか。
4. **可逆性**：冷却・再加熱で曲線が戻るか。戻らなければ平衡的Tmとしての解釈は限定される。
5. **凝集との接続**：構造転移と光散乱を同時に測り、保存後のSEC・粒子・potencyでも確認したか。
6. **時間軸**：短い熱stressの順位を、実時間保存の有効期間へ直接外挿していないか。

## 抗体×AIとの接続

安定性AIの教師ラベルでは、`Tm1`、`Fab Tm`、`Tagg`、40°C保存後の`% monomer`を一つの「stability」へ混ぜてはいけない。抗体format、配列、濃度、pH、buffer、添加剤、装置、加熱速度、ピーク番号と割当て、保存温度・時間をprovenanceとして保持し、構造転移・凝集開始・長期劣化を別タスクにする。ピークが測定範囲外だった値は通常の欠測ではなく、上限・下限付きの打ち切り値として扱う。

同じ親抗体の変異体や、同じ抗体を多数の製剤で測ったデータをランダム分割すると、モデルは抗体系列や処方を記憶できる。親抗体・clonotype単位の分割に加え、未知のbufferや測定施設で外部検証する。予測値だけで配列を最適化せず、低安定性ドメインの仮説を立て、変異後の結合、発現、Tm/Tagg、保存安定性を実験で再測定する。

## 重要用語（8語）

- **構造安定性**：抗体が天然状態の高次構造を保つ傾向。
- **Tm**：特定条件・測定法で観測された熱転移の中点またはDSCピーク温度。
- **Tonset**：構造転移シグナルが所定の基準で立ち上がる温度。
- **Tagg**：光散乱などで会合・凝集シグナルが検出され始める温度。
- **apparent Tm**：不可逆変性や凝集、加熱速度の影響を含む見かけのTm。
- **DSC**：加熱に伴う過剰熱容量を測定する示差走査熱量測定。
- **nanoDSF**：主に内因性蛍光変化から熱による構造変化を追う方法。
- **部分変性状態**：天然構造の一部を失い、凝集核になり得る中間状態。

## 理解確認問題2問と各問題の簡潔な模範回答

### 問1

同じbuffer中で候補AのTm1は70°C、候補Bは66°Cだった。Aの方が長期保存で凝集しにくいと結論するために不足している情報を二つ挙げよ。

**模範回答：** まず各ピークがどのドメインの転移かを確認する必要がある。さらに予定濃度・製剤でのTaggと、実時間または加速保存後の単量体率・粒子・活性を比較しなければ、凝集しにくさは結論できない。

### 問2

nanoDSFの構造転移開始と光散乱の増加がほぼ同時で、冷却後に元の曲線へ戻らなかった。このTmを平衡的な分子定数として扱いにくいのはなぜか。

**模範回答：** 変性直後に不可逆凝集が起き、変性状態が反応系から除かれている可能性が高いからである。観測Tmは加熱速度や濃度、凝集速度を含むapparent Tmとして解釈する。
