# Day 001：抗体研究の全体地図

## 今日の問い

抗体の「配列」「立体構造」「抗原結合」「生物学的機能」「実験測定」「開発適性」は、どのような因果関係でつながり、抗体工学論文ではどこを確認すべきだろうか。

## 本文

### 1. 抗体工学は「配列を変える技術」だけではない

抗体工学の出発点はアミノ酸配列だが、目的は配列そのものを美しくすることではない。配列を変えると原子間相互作用や表面の電荷・疎水性が変わり、立体構造、抗原への結合、細胞での作用、製造・保存時の挙動まで連鎖的に変化する。したがって候補抗体を評価するときは、**配列→構造→結合→機能→開発適性**という因果の鎖をたどる必要がある。逆向きに考えれば、望ましい機能を定義し、それに必要な結合特性を決め、最後に実現可能な配列を設計する仕事ともいえる。

典型的なIgGは、同一の重鎖2本と同一の軽鎖2本からなる。重鎖と軽鎖の可変ドメイン（VH、VL）が対になり、各鎖の3つの相補性決定領域（CDR）、合計6ループを中心に抗原結合面（パラトープ）をつくる。一方、重鎖定常領域を中心とするFcはFc受容体や補体成分と相互作用し、免疫細胞の動員などを担う。つまり「どこに結合するか」と「結合後に何を起こすか」は、同じ抗体分子内で分業されている。ただしFabとFcは完全に独立ではなく、ヒンジの柔軟性、糖鎖、抗体フォーマットなどが分子全体の挙動へ影響する。この基本構造と機能分担は、抗体論文を読む最初の座標軸になる。[Schroeder & Cavacini, 2010](https://doi.org/10.1016/j.jaci.2009.09.046)

### 2. 配列から結合と機能まで

1残基の置換でも、側鎖の大きさ、電荷、水素結合能、疎水性が変わる。変異が抗原と直接接触する位置なら、接触面の形状や相互作用が変わりやすい。接触部位から離れていても、CDRの向きやVH–VL間の配置、局所的な柔軟性を変えることで結合へ間接的に影響しうる。したがって、配列差と結合差の相関だけでは機構の証明にならない。構造情報、変異実験、速度論測定などを組み合わせて因果を検討する必要がある。

結合にも複数の側面がある。親和性は平衡解離定数 \(K_D\) で表されることが多いが、同じ \(K_D\) でも結合速度 \(k_{on}\) と解離速度 \(k_{off}\) の組合せは異なりうる。また、精製抗原へ強く結合しても、細胞膜上で目的エピトープに到達できるとは限らない。結合後に受容体を遮断するのか、架橋して活性化するのか、抗原を細胞内へ取り込ませるのかでも、生物学的な結果は変わる。「強く結合した」は、望ましい機能を示したことと同義ではない。

### 3. 実験は因果の鎖を観測可能な値へ変換する

配列は直接読めるが、構造・結合・機能・開発適性の多くは実験を介して観測される。ELISAの吸光度、SPRの \(K_D\)、細胞アッセイのEC50、熱変性の融解温度 \(T_m\)、凝集体比率は、いずれも性質そのものではなく、特定条件下の測定値である。抗原の固相化、抗体の価数、温度、pH、濃度、細胞株、反応時間、解析モデルが変われば値も変わりうる。

そこで論文のグラフを見るときは、縦軸の数値だけでなく、①何を測ったか、②どの分子形式で測ったか、③どの条件・対照を用いたか、④反復数とばらつき、⑤その測定からどこまで主張できるかを確認する。実験法は単なるMethodsの細部ではなく、データの意味を定義する部分である。細胞画像解析で撮像条件やアノテーション規則がラベルを左右するのと同じく、抗体研究ではassay条件が教師ラベルを形づくる。

### 4. 良いbinderと良いdrugは同じではない

治療用抗体には目的抗原への結合と望ましい生物活性に加え、十分な発現量、溶解性、構造安定性、低い凝集傾向、低い非特異的結合、保存中の化学的安定性などが求められる。これらを、製造・製剤化・投与・保存まで含めて開発しやすい性質、すなわち**developability（開発適性）**として評価する。臨床段階の抗体137件を共通条件で調べた研究では、12種類の物性アッセイを用い、単一の不利な測定値だけで成否を断定せず、複数指標を総合する必要性が示された。[Jain et al., 2017](https://doi.org/10.1073/pnas.1616408114)

重要なのは性質間のトレードオフである。たとえばCDRに疎水性残基や正電荷を加えると標的との相互作用が強くなる場合がある一方、非特異的結合や自己会合のリスクが増える場合もある。結合力だけを最大化する設計は、薬としての総合点を下げかねない。抗体工学は、一つの指標の最大化ではなく、複数の制約下で実用的な解を探す多目的最適化である。

### 5. 抗体研究を「閉じた検証ループ」として見る

実際の研究は一直線ではない。候補配列を設計・取得し、発現・精製し、結合、機能、物性を測り、結果から次の変異を決める。この **design–build–test–learn** の反復によって候補を絞り込む。構造解析や計算予測は仮説を狭めるが、予測値は実験値の代わりではない。逆に、実験値だけを並べても、分子機構や測定条件を無視すれば一般化できない。

たとえば、あるCDR変異体でELISAシグナルが上がったとする。ここから直ちに「高親和性化に成功」とは言えない。発現量が増えて提示される抗体量が変わった、二価結合によるavidityが強まった、固相化抗原へ非特異的に付着した、といった別の説明が残るからである。そこで発現量を正規化し、SPRで速度論を測り、無関係な抗原への結合を対照にし、細胞上の天然構造の抗原でも機能を確かめる。さらに安定性と自己会合を調べれば、「配列変更が薬候補として有益か」という一段広い問いへ進める。このように、一つの結果に対する代替説明を次の実験で減らすことが検証ループの核心である。

初学者が今日持ち帰るべき視点は、「この論文は因果の鎖のどこを入力とし、どこを測り、どこまでを結論としているか」である。配列から機能までの全段階を一つの研究が直接証明することは少ない。著者が測定した部分と推論した部分を分け、欠けた矢印を見つけることが、抗体工学論文を批判的に読む第一歩になる。

## 論文を読むためのポイント

まず、研究対象が完全長IgG、Fab、scFv、VHHなどのどの形式で、重鎖・軽鎖のどの領域を改変したかを特定する。次に、結合性の主張が \(K_D\)、EC50、濃縮度、あるいは単一濃度でのシグナルのどれに基づくかを確認する。これらは交換可能な指標ではない。最後に、「結合が改善した」から「治療候補として優れる」へ進む間に、細胞機能、特異性、安定性、PKなど、どの証拠が提示され、何が未測定かを一覧にする。論文中の *potent*, *specific*, *stable*, *developable* は、必ず操作的定義と測定法へ戻って読む。

## 抗体×AIとの接続

抗体AIでは、配列や構造が入力、affinity・発現量・安定性などが教師ラベルになりうる。しかしラベルはassayから生成されるため、抗体形式、抗原、濃度、装置、解析法というprovenance（由来情報）が欠けると、異なる意味の数値を同じ目的変数として混ぜてしまう。また、近縁配列をtrain/testへ分散すると、未知抗体への一般化ではなく系列の補間を評価する危険がある。

機械学習で臨床段階抗体の親和性と非特異的結合を同時最適化した原著では、配列特徴から候補を提案しただけでなく、変異体を作製し、親和性、非特異的結合、細胞活性、自己会合、熱安定性を実験検証した。ここで学ぶべきはモデル名ではなく、**予測対象を明示し、複数目的を扱い、最後に実験で因果の鎖を閉じた**設計である。[Makowski et al., 2022](https://doi.org/10.1038/s41467-022-31457-3)

## 重要用語5〜8語

| 用語 | 意味 |
|---|---|
| 可変領域（V領域） | 抗体ごとに配列が多様で、主に抗原認識を担う領域 |
| CDR | 可変領域内の多様性が高いループ。抗原結合面の中心を構成する |
| パラトープ | 抗体側の抗原結合面 |
| エピトープ | 抗原側で抗体に認識される部位 |
| affinity | 1つの結合部位どうしの結合の強さ。しばしば \(K_D\) で評価する |
| assay | 性質を操作的に定義し、測定値へ変換する実験系 |
| developability | 製造、製剤化、保存、投与などを可能にする総合的な開発適性 |
| provenance | データが、どの試料・条件・測定・処理から得られたかという由来情報 |
